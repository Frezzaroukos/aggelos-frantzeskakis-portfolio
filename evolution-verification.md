# Aggelos Frantzeskakis Portfolio Evolution — Verification Notes

The current portfolio is a vertical editorial experience centered on the Aggelos Frantzeskakis / AF identity. The hero then combines the asymmetric headline, responsive Pegasus scene, scroll-aware depth, pointer parallax on fine pointers, navigation-linked banking, and a restrained hover/floating response.

The current narrative is organized as Arrival, Selected Work, Skills, Tech Stack, Profile, and Contact. Project cards are driven from the static GitHub snapshot and now normalize GitHub's raw `stargazers_count` and `forks_count` values into the `stars` and `forks` fields consumed by the UI. Morfos and forked repositories remain excluded from the curated project view, while private projects are visibly labeled.

The language switch persists EN/EL, the theme switch persists light/dark graphite styling, and the navigation exposes keyboard-friendly controls, a mobile menu, scroll progress, and a Back to top action. Project dialogs close through Escape or the close control and lock body scrolling while open. The Vite Manus storage proxy is no longer required for these assets, and the standalone preview serves the HTML, artwork, mark, and PDF from the built static bundle. The repository remains private and the latest portfolio changes are synchronized to its `main` branch.
