# Αναφορά

**Πρόχειρες σημειώσεις → επίσημο έγγραφο.** Τοπικά, χωρίς server.

**[▶ Δοκίμασέ το](https://frezzaroukos.github.io/anafora/)**

---

## Το πρόβλημα

Ο γεωπόνος γυρίζει από το χωράφι με σημειώσεις στο κινητό και κάθεται το βράδυ
να γράψει την έκθεση. Ο δικηγόρος βγαίνει από συνάντηση και πρέπει να γράψει
σημείωμα στον φάκελο. Ο τεχνικός τελειώνει εργασία και χρωστάει αναφορά στον
πελάτη.

Είναι η ίδια δουλειά κάθε φορά: **παίρνεις κάτι πρόχειρο και το κάνεις επίσημο.**
20 λεπτά, κάθε μέρα, για κάτι που δεν προσθέτει τίποτα.

## Τι κάνει

Γράφεις όπως σου βγαίνει — με λάθη, χωρίς τόνους, τηλεγραφικά:

> *«Επισκεψη στου Παπαδακη το χωραφι στις Πηγες, ελιες. Ειδα δακο σε αρκετα
> δεντρα στη βορεια πλευρα... Ξαναπερναω σε 2 βδομαδες.»*

Και βγαίνει δομημένο έγγραφο, έτοιμο για εκτύπωση ή PDF:

| | |
|---|---|
| **Παραγωγός** | Παπαδάκης |
| **Τοποθεσία** | Πηγές, ελαιώνας |
| **Καλλιέργεια** | Ελιές |
| **Επόμενη επίσκεψη** | σε 2 εβδομάδες |

> **Ευρήματα** — Δάκος σε αρκετά δέντρα στη βόρεια πλευρά, κιτρίνισμα φύλλων
> **Οδηγίες** — Ψεκασμός σε 5 μέρες (εκτός αν βρέξει), λίπανση τον επόμενο μήνα

*(πραγματικό αποτέλεσμα, τοπικό μοντέλο, 22 δευτερόλεπτα)*

## Γιατί τοπικά

Ένας δικηγόρος **δεν επιτρέπεται** να στείλει στοιχεία εντολέα σε cloud —
δικηγορικό απόρρητο. Ένας γεωπόνος κρατά δεδομένα παραγωγών.

Με **Ollama** τίποτα δεν φεύγει από τον υπολογιστή. Προεπιλογή είναι το
[Llama-Krikri](https://huggingface.co/ilsp/Llama-Krikri-8B-Instruct) του ΙΕΛ —
ελληνικό μοντέλο, που διορθώνει και ορθογραφία.

Όποιος προτιμά cloud βάζει δικό του κλειδί (OpenAI / Anthropic / Groq). Το
κλειδί μένει στη συσκευή· δεν υπάρχει server σε αυτό το demo.

## Ο κανόνας που δεν σπάει

**Το μοντέλο δεν συμπληρώνει ό,τι δεν ειπώθηκε.** Ό,τι λείπει μένει «—».

Σε έγγραφο που πάει σε παραγωγό ή σε δικογραφία, ένα εφευρημένο στοιχείο δεν
είναι ενόχληση — είναι ευθύνη.

## Πώς κλιμακώνεται

Τα πρότυπα ζουν σε ένα αρχείο (`src/templates.ts`). Κάθε ένα ορίζει πεδία και
ενότητες· ο αγωγός είναι ο ίδιος.

```
σημειώσεις → δομημένα πεδία → έγγραφο → PDF → αρχείο
```

**Νέο επάγγελμα = νέο πρότυπο, όχι νέος κώδικας.** Σήμερα: έκθεση επίσκεψης
αγρού, σημείωμα υπόθεσης, αναφορά εργασίας.
